# Google Workspace Discovery inputs

These files are the authoritative Google Discovery documents used to generate
Rook's browser-native Workspace client. They were copied from
[`googleapis/google-api-nodejs-client`](https://github.com/googleapis/google-api-nodejs-client)
at commit `a52fd4217a5ed171cafe6a5a4e895ca421ad3b39`. That official client and these
Discovery snapshots are Apache-2.0 licensed.

Update the snapshots deliberately, run `vp run generate`, review the changed
model surface, and run the browser boundary suite before merging.
