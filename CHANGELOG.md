# Changelog

## 0.1.0 - 2026-08-24

### Added

- Browser-native Google Workspace application covering Drive, Gmail, Calendar, Docs, Sheets, Slides, Chat, and People.
- Structured Gmail sending that preserves exact plain text and accepts native `File` attachments.
- Native Drive upload and workspace download helpers.
- Generated TypeScript surfaces, searchable member metadata, and model guidance from pinned Google Discovery documents.
